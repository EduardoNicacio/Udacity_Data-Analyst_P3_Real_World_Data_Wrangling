# Check Your Work

Once you submit your project, we'll review your work and give you feedback if there's anything that you need to work on. Please make sure your code is error-free so reviewers can run it to gather, assess, and clean data as you did, and reproduce the visuals you created.

If you'd like to see the exact points that your reviewer will check for when looking at your work, you can have a look over the project [rubric](https://learn.udacity.com/rubric/5120).

## Task List

Before you submit your project, make sure that the following files are included in a `.zip` file:

- [ ] A complete version of `Data_Wrangling_Project_Starter.ipynb`.
- [ ] If you download the data manually, include the source datasets used for the project. Or a `.txt` file with links to your dataset hosted on Google Drive/Dropbox that can be accessed.
- [ ] If gathering data programmatically, provide your code in the notebook.
- [ ] One or more raw datasets you stored locally. These datasets are the data before the cleaning.
- [ ] The final cleaned dataset you stored locally. This dataset is the cleaned data after the combination and elimination of variables.
