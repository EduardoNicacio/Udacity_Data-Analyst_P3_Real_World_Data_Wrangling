# Environment and Dependencies

This project can be completed inside the Udacity classroom on the Project Workspace provided on the next **Workspace** page. The workspace includes essential Python packages for completing the project, along with starter files. **However, if you choose to explore methods beyond those taught in the course, the workspace may not include all the necessary packages. In that case, you may wish to work on the project on your local machine**.

If you're using the workspace, you can skip the rest of this page.

You may also wish to use additional libraries and dependencies not available in the workspace, in which case you’re welcome to work locally. If you decide to work locally, you must download the starter [Jupyter Notebook](https://video.udacity-data.com/topher/2023/March/640b7825_data_wrangling_project_starter/data_wrangling_project_starter.ipynb) (opens in a new tab), and the following software requirements apply.

## Task List

The workspace has the latest versions of the following dependencies installed.

If you're working on your own machine, ensure you have at least the packages listed below. If you’ve been following along during the course, you may already have these set up, but it’s good to check.

- [ ] NumPy - for numerical data handling
- [ ] pandas - for data manipulation and analysis
- [ ] Matplotlib - for basic visualizations
- [ ] requests - for API and web-based data gathering
- [ ] BeautifulSoup - for web scraping (if applicable)
- [ ] Pillow (PIL) - for image handling (if applicable)
- [ ] SQLAlchemy - for database interaction (if applicable)
- [ ] Scikit-learn - for data assessment and preprocessing
- [ ] Seaborn - for advanced visualizations
- [ ] Openpyxl - for handling Excel files (if applicable)
