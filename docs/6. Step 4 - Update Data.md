# Step 4: Update Data

In this step, you’ll update your database or data store with the cleaned data, following best practices for organized data storage.

## Data Storage Guidelines

- **Maintain Different Versions of Data**: Keep both raw and cleaned versions of your datasets.
- **Use Informative File Naming**: Name each file descriptively (e.g., `raw_data_weather.csv`, `cleaned_data_weather.csv`) to easily identify contents and version.
- **Save Data in a Structured Format**: Store both raw and cleaned data in a clear, organized manner.

**Note**: You are not required to use a relational or non-relational database; local file storage is acceptable.

## Task List

Before going any further, make sure you've done the following:

- [ ] Maintain at least two different instances of the data (raw and cleaned data).
- [ ] Name dataset files informatively.
- [ ] Save raw and cleaned data to your database/data store.
